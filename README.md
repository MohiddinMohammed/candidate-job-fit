# Gouse Mohiddin Mohammed — Product Portfolio

Recruiter-first portfolio for Product Manager, Product Owner and Technical Product roles.

## Stack
Next.js 14 · TypeScript · Tailwind CSS · React · Lucide React

## Run locally
```bash
npm install
npm run dev
```

## Before publishing
- Add the real CV as `public/resume.pdf`.
- Replace the placeholder LinkedIn URL in `app/page.tsx`.
- Replace `your.email@example.com` with the real email address.
- Add or replace visuals only where they improve a case study.

Case studies intentionally avoid confidential company information, customer data, unsupported metrics and invented responsibilities.
